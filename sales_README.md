# Sales Performance Dashboard

## Overview
Analyze 3 years of raw sales data (100,000+ rows) to identify top-performing regions, products, and sales reps. Build a comprehensive visual dashboard.

## Dataset
- Generated sample data (or plug in your own CSV)
- Fields: date, region, product, sales_rep, units_sold, unit_price, revenue

## Dashboard Charts
1. Monthly Revenue Trend (line chart)
2. Revenue by Region (bar chart)
3. Revenue by Product (horizontal bar)
4. Top 10 Sales Reps
5. Yearly Revenue Growth
6. Monthly Revenue by Product (multi-line)
7. Region Revenue Share (pie chart)

## KPIs Tracked
- Total Revenue
- Total Units Sold
- Top Region / Product / Sales Rep
- Average Monthly Revenue

## Tech Stack
- Python, Pandas, NumPy
- Matplotlib, Seaborn

## How to Run
```bash
pip install -r requirements.txt
python sales_dashboard.py
```
